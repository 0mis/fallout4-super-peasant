# Release trailer source

Run `python media/render_trailer.py --out artifacts/One-Punch-Man-Fallout4-Release-Trailer.mp4` from the repository root with Python3.11+, Pillow13 and FFmpeg installed. On Windows the default fonts are Impact and SegoeUI; these fonts are supplied by the local Windows installation, not redistributed here. Pass --font to use another locally licensed headline font.

The selected gameplay captures and edit source are included.10fps/6fps source motion is retained in a30fps H.264/yuv420p MP4 with stereo AAC audio and fast-start metadata. No optical-flow frames or commercial music are used. Audio is original deterministic synthesized percussion/bass.

The footage predates the final native build and is labeled development gameplay. It illustrates the same mod rather than proving final-profile timing.
