# Visual and audio assets

The project maintainer confirmed permission to redistribute the current converted model and sound assets for this public mod release on October31,2026. This statement records the maintainer's permission confirmation; it is not a transfer of the upstream copyright or a new blanket license from the original rights holders.

The four `Meshes/SuperPeasant/*.nif` files contain geometry originating in Totally Accurate Battle Simulator (Landfall Games), converted and fitted for Fallout4. The default pair also contains locally authored costume edits, a procedural bald head/face and a simulated cape inspired by Saitama. The two `_TABS` variants preserve the earlier converted appearance. Editable fitted/costumed Blender files and the local authoring scripts are included for the mod's development.

The24 WAV files under `Sound/FX/SuperPeasant` originate in TABS: six swing effects, five hits, six attack vocals, five death vocals, one unit-placement effect and one mono-downmixed fist-loop effect. They are not represented as newly recorded or public-domain sounds.

The DDS files are generated palettes, flat normal/specular maps and costume maps. Their source values and local generation scripts are included; some palette values came from the original model materials.

These third-party assets, their converted/editable forms and the underlying character rights are excluded from the repository's code-license grant. Original rights remain with Landfall Games and other applicable rights holders. The permission to include them in this mod does not mean this repository can grant unrestricted reuse, resale or relicensing for unrelated projects. Obtain permission from the applicable rights holders for uses outside the permitted release.

Bethesda's standalone skeleton, game masters and animations are not redistributed as development dependencies. Model export uses a skeleton supplied by the developer's own tools/game installation. PyNifly is a separate exporter with its own license.

Only this notice, credited converted mod assets and reviewed source files are published. The private game extraction workspace and unrelated game archives are not part of the release.
